# 富士封面整组协调 · 2026-10-25

用户希望整组摆放与搭配更和谐。本轮继续处理用于拍摄的 8 款富士封面，不扩展到独立 Library 的真实包装收藏卡。两款 Classic 作为视觉参照保留，细化其余 6 张。Kodak Portra 400 保留，在整组比较中作为已有邻近封面一起检查。

## 设计目标

上一版强化了各款识别色，但品牌字、Professional、片速和片名同时放大，三列排列时视觉重点过多。本轮统一信息层级、边距、品牌区比例和辅助文字大小；保留每款原有的字体、标签结构、识别色和几何标记。

- 六张采用绿色品牌头部，收敛品牌区与辅助文字的视觉比重，形成顶部品牌、中部片名、底部参数的共同层级。
- 每张只突出片名。FUJICHROME / FUJICOLOR / NEOPAN 和 Professional 退为小字，片速、画幅与工艺移入小尺寸页脚，不再以巨大数字争夺视线。
- PROVIA 保留蓝金与黑色底部；Velvia 保留象牙白、蓝块和红色 Fuji 方标；ASTIA 保留金色片名区域与紫蓝底部；ACROS 保留黑白银灰和折带；C200 保留斜体与暖色斜线；Pro 400H 保留黑色名称牌和紫色燕尾。
- 色彩使用更沉稳的印刷色。C200 的暖覆盆子红与 Pro 400H 的冷灰紫拉开差别，减少相邻紫色卡片的拥挤感。
- 保持平面、满版、方形包装正面与细微纸张纹理，圆角由 App 绘制；图片内不加 JustShoot、RAW → sRGB 或额外宣传文字。

包装和官方模式图示依据沿用 [上一轮调研](../fujifilm-cover-refresh-2026-10-25/README.md) 与 [三款缺失封面调研](../film-covers-2026-10-25/README.md)。这些仍是经过重排的 App 封面适配稿，不宣称为未经改动的历史包装。

## 制作与接入

使用内置 `image_gen` 逐款编辑，原封面为编辑对象，当前九宫格为搭配参考，完整提示词见 `prompts.json`。原始生成 PNG 留存在生成目录；1024×1024 sRGB HEIC 保存到项目中已有的六个专属封面路径，以便首页、拍摄页和选择器共用。

未修改 LUT、用户照片、导入数据、首页排序或 UI 布局。原始包装收藏图与目录也保持不变。现有有界异步缩略图解码及预热继续使用，不增加 UI 更新时的磁盘读取。

资源、旧文件校验和与验证记录见 `assets.json`、`baseline-hashes.json`、`validation.json`。优化前的六张封面已另存到任务可视化目录，便于回看。

## 验证结果

- iPhone 17 / iOS 26.4.1 模拟器构建、安装和运行成功，无新增编译警告。
- 首页封面准备、选择器实际图片准备、启动准备与胶片目录共 16 项测试通过；九款均可解码为对应显示尺寸。
- 检查 110px 缩略图及 App 首页三列排布，片名、绑定关系和圆角显示正常。保留现有 ImportValidation 自定义测试条目。
- 579 个基线资源中仅预期的六张专属封面改变；550 张原始收藏包装、两款 Classic、Portra、cards.json 与 LUT 表校验和一致。

本轮只做封面资源调整。未进行相机实拍或物理设备性能测量。
